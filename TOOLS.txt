
Para el desarrollo del proyecto sera necesario que bibliotecas o controles podemos usar.

Entre los frameworks de programacion podemos ver

JNI:  JNI o  traducida como Java Native Interface: Simplemente es un framework (una plantilla) que permite a los programas compilados en la maquina virtual de java  (JVM) pueda interactuar con otros programas escritos en C, C++ o ensamblador. De forma que podemos traducir function de un lenguaje en este caso java a c o sus derivados; 
Esto con el fin de optimizar la memoria y espacio, asi como operaciones de bajo nivel, utiles para el desarrollo de este motor.


Bindings

 Lightweight Java Game Library (LWJGL): Es una biblioteca usada por java destinada para juegos comerciales del lenguaje de java. Aunque
indica una biblioteca actua como un conjunto de bibliotecas. Los cuales dan acceso a librerias nativas por medio de bindings(en este caso librerias nativas de c/c++) y por ende a las funciones de tres librerias:

Entre ellas podemos ver:

-OpenGL:Esta libreria permite acceder a funciones de graficos de 3d y 2d, es general permite dibujar en la pantalla usando la gpu yotras funciones: glClear, glDrawArrays, glVertex3f

-OpenAL: Proporciona funciones de manejo de audio, como lo es reproducir sonidos, musica y efectos en 3d

-OpenCL: Proporciona funciones para calculos pesados de CPU/GPU util para operaciones de optimizacion.


Framework:

LibGDX: Como dijimos es un framework que usa el conjunto de bindings anterior con respecto a las graficos de escritorio. En su plantilla basica podemos ver una extension de la clase  Aplication Adapter o Game. La plantilla ofrece funciones basicas de:

create() = inicializas recursos (texturas, sonidos, etc.).

render() = Se ejecuta en cada frame, dibujar y ejecutar cada frame..

dispose() = Libera memoria al cerrar.

JavaFX: Este framework se uso para el desarrollo de interfaces graficas, como es el caso de crear aplicaciones de escritorio con ventanas, menus, botones, animaciones y graficos 2d/3d basicos.



Biblioteca:

JOML: Esta libreria incluye en conjunto de funciones que permiten acceder a un conjunto de funciones y clases operaciones matematicas relacionadas con vectores y matrices, mas como se planteo la idea del motor, es probable que se requieran realizar transformaciones o demas operaciones de graficos 3d.

Entre algunas de las clases que proporciona estam Vector2f, Vector3f, Matrix4f y Quaternionf.
